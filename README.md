# Introduccion
Este proyecto se trata de un programa para una libreria, el cual ayuda a organizar datos relacionados a libros, ayudando 
tambien a la consulta, venta y recoleccion de datos de clientes unicos. Se incluye tambien la edicion de los datos ya ingresados como autor, clave, valor neto, etc.
Se encuentra dividido en 3 archivos importantes, main.py, menu.py y funciones.py, siendo main el archivo de ejecucion, menu alberga todas las funciones relacionadas a
mostrar en pantalla los menus de seleccion y funciones contiene todo lo relacionado con modulos utilizados para realizar tareas de validacion, ingreso, eliminacion de
datos y calculos para cumplir el proposito de este programa.
